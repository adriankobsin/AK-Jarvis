# Business development

1. **Ideal clients** (knowledge base: clients, markets). If missing, ask Adrian and save.
2. **Find**: web search and browser for yachts in build/refit at yards in the region, new venue
   openings, tenders; existing contacts in Outlook. Record source and date for each lead.
3. **Qualify**: fit, timing, budget signals, decision-maker, warm path (who we know). Score 1–5.
4. **Outreach**: short personalised drafts (email/LinkedIn), referencing a relevant Wave project
   type. **Never send without approval.**
5. **Track**: keep the pipeline in a spreadsheet in SharePoint (or Wave Business Hub when it has a CRM):
   stage, next step, date, value. Weekly summary: new leads, follow-ups due, deals at risk.
